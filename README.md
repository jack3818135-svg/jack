# 全公司 OKR 管理系統（2026 年起）

此專案為純前端靜態網站，依照公司組織架構提供：

- 主管登入後，可為同仁建立年度 OKR（O1~O5，可少於 5 個）。
- 同仁登入後，可填寫 Q1/Q2/Q3/Q4/YearEnd 檢核點進度與說明。
- 以 YearEnd 進度 × 權重計算個人年度達標率。
- 可於新年度帶入上一年的 OKR 定義（不帶進度），支援 2026 年起逐年追蹤。
- 提供職能別平均達標率統計表，供年終/年底檢視。

## 使用方式

1. 直接開啟 `index.html`。
2. 選擇角色（主管/同仁）與帳號登入。
3. 主管：設定同仁當年度 OKR 並儲存。
4. 同仁：填寫各檢核點進度並儲存。
5. 切換年度可追蹤歷年資料；可使用「帶入上一年 OKR」。

## 備註

- 資料儲存在瀏覽器 `localStorage`。
- 示範版採簡化登入，正式部署建議串接公司 AD/SSO 與權限控管。
