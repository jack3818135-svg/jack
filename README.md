# 康舒(6282)分析儀表板

這是一個靜態網頁工具，協助你追蹤康舒科技（6282）的：

- 基本面（營收 YoY、毛利率、營益率）
- 券商分點買賣超
- 三大法人買賣超
- 2030 產業情境（樂觀/中性/保守）

## 使用方式

1. 直接以瀏覽器開啟 `index.html`。
2. 更新表格中可編輯儲存格（深色欄位）。
3. 按下「重新計分」計算紅黃綠燈。
4. 依分數作為每週觀察依據（非投資建議）。

## 計分邏輯（最高 10 分）

- 月營收 YoY：0~3 分
- 營益率：0~2 分
- 三大法人合計：0~3 分
- 券商分點淨買賣：0~2 分

燈號參考：
- 7~10 分：綠燈（偏多）
- 4~6 分：黃燈（震盪）
- 0~3 分：紅燈（防守）
